# Al Salam Pit Stop Challenge (concept demo)

Single-file game (`index.html`, vanilla HTML/CSS/JS, no build). Open it in a browser.

Edit the `CONFIG` object at the top of the script to change the sponsor name, logo, colours (`accent`, `accent2`, `deep`, `cream`), event name, prize text, penalties, tiers, launch timing and kiosk reset time.

Notes
- The logo and colours come from the bank's own artwork and need the bank's approval before any public use.
- The event name is plain text and needs clearance.
- Fonts load from Google Fonts; self-host them for an offline kiosk.
- Consent and privacy copy should go through compliance.
